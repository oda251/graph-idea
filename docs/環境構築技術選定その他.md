# ESLint
### ↓こういうの
```
14:3   error  'onClick' is missing in props validation           react/prop-types
17:5   error  'React' must be in scope when using JSX            react/react-in-jsx-scope
```
- フレームワークとかで問題ないのに、eslintが対応していないパターン

### 解決
- `rules`とかの記述を下に持ってくる
```
export default defineConfig([
  {
    files: ["**/*.{js,mjs,cjs,ts,mts,cts,jsx,tsx}"],
    plugins: { js },
    ignores: [
      "node_modules",
      "dist",
      "build",
      "public",
      "coverage",
      "stories/**/*.{js,ts,jsx,tsx}",
    ],
  },
  tseslint.configs.recommended,
  pluginReact.configs.flat.recommended,
  {
    languageOptions: { globals: globals.browser },
    rules: {
      "react/jsx-uses-react": "off",
      "react/react-in-jsx-scope": "off",
      "react/prop-types": "off",
    },
  },
]);
```
